隐私政策

PrettyFace 发布台 · 最近更新：2026-11-10

本隐私政策说明 PrettyFace 发布台（下称「本应用」）在你授权后， 如何访问、使用、存储与共享你的数据。本应用由 Pretty Face (Shanghai) Medical Equipment Co., Ltd.（下称「本公司」）运营， 为公司内部工具，不对外提供服务注册。

一、我们访问哪些数据

仅在你明确授权后，本应用会通过官方 API 访问以下范围内的数据：

  • YouTube：所授权频道的频道名称与 ID、视频列表、上传视频所需的上传权限； 以及在发布后读取该视频的处理状态与链接。
  • Facebook / Instagram：所授权主页或个人专业号的名称与 ID、 发布贴文与快拍所需的内容发布权限。

本应用不会访问你的 Gmail 邮件内容、Google 云端硬盘文件、日历、通讯录、 浏览记录，也不会读取与你所管理频道无关的任何账号数据。

二、我们如何使用这些数据

  • 把你提交的素材上传到你指定的频道或主页
  • 在界面上显示频道名称与账号标识，供你确认发布目标
  • 记录发布结果（成功与否、回执编号、链接），便于你事后核对

数据仅用于上述目的，不用于广告投放、用户画像、信用评估或任何二次分析。

三、数据存储与安全

本应用在你自己的电脑上运行，不设云端服务器：

  • 授权凭据（OAuth refresh token）保存在本机目录 .data/tokens.json
  • 浏览器登录态（如使用浏览器通道）保存在本机 cookies/ 目录
  • 发布记录保存在本机，不上传至任何第三方

我们不将这些凭据上传到外部服务器，也不做跨设备同步。删除本地文件即可彻底移除凭据。

四、数据共享

我们不向任何第三方出售、出租或共享你的数据。 数据只在你的设备与你所授权的平台（Google / Meta）之间传输，用于完成你主动发起的发布操作。

五、数据保留

凭据与发布记录一直保留在你本机，直到你主动删除对应账号或文件。 你可以随时在 Google 账号权限页 撤销本应用的访问权，撤销后本应用将无法再调用相关 API。

六、你的权利

  • 随时撤销授权（Google 账号权限页 / Meta 应用设置）
  • 要求查看或删除本机保存的凭据与记录
  • 停止使用并删除本应用的全部本地数据

七、Google 用户数据的使用承诺（Limited Use）

本应用对 Google 用户数据的使用遵循 Google API 服务用户数据政策， 包括其中的 Limited Use（有限使用）要求：

  • 仅使用为实现本应用已声明的功能所必需的数据
  • 不将 Google 用户数据用于广告用途
  • 不将 Google 用户数据转让给第三方，法律要求的情形除外
  • 不将 Google 用户数据用于训练通用人工智能或机器学习模型
  • 仅由人工读取，除非获得明确同意或出于安全目的

八、YouTube API 服务条款

本应用使用 YouTube API Services。使用本应用即表示你同意受 YouTube 服务条款约束， 并同时适用 Google 隐私权政策。

九、政策变更

如本政策发生实质性变更，我们会更新本页顶部的日期。继续使用即表示接受更新后的政策。

十、联系我们
