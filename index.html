PrettyFace 发布台

内部社媒内容发布工具

PrettyFace 发布台 是一个供公司内部运营人员使用的社媒内容发布工具。 它把同一份视频或图文素材，一次提交到多个已授权的社交媒体账号，省去逐个平台手工上传的重复劳动。

这个应用做什么
  • 通过 YouTube Data API v3 上传视频到已授权的 YouTube 频道
  • 通过 Meta Graph API 发布 Facebook 主页贴文、快拍与 Instagram 内容
  • 记录每次发布的平台、账号、结果与回执链接，便于核对

授权方式

应用只在你主动点击「授权」时，通过 Google 或 Meta 的标准 OAuth 流程获取访问权限。 授权范围限于上传内容与读取频道基本信息，不读取你的邮件、云盘、通讯录或浏览记录。 所有凭据仅保存在你运行本工具的这台电脑上。
